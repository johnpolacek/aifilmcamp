# AI Film Camp identity

The approved logo is **Ember Lens, 20% wider**, selected September 5, 2026.
`ember-lens.svg` is the canonical master for the website and native app.

Preserve this exact silhouette and the transparent circular opening. The outer
flame is 120% of the selected refined design's width; its height and inner circle
are unchanged. Use a solid fill, without outlines, an enclosing ring, or decoration.
Use amber `#FBBF24`, white on dark backgrounds, or dark `#1F1A15` on light backgrounds.
UI instances may inherit the platform's theme color.

Run `pnpm brand:generate` from the repository root after an approved master edit.
It generates the shared web path, favicon (darker amber `#D97706` on transparent, cropped to the mark bounds), public SVGs, native template vector,
and every macOS app icon size. The web Logo and Apple icon use the generated path;
the macOS welcome screen and scene rail use the BrandMark asset through CampLogo.
The app tile uses the amber mark on a dark rounded square.

Earlier studies under `apps/macos/design/logo-concepts` are historical concepts,
not production assets. Do not restore a prior concept or a stock flame as branding.

# AI Film Camp identity

The approved logo is **Ember Lens with matched crescent C, 15% wider**, selected
September 6, 2026.
`ember-lens.svg` is the canonical master for the website and native app.

Preserve this exact silhouette and transparent crescent C. The outer flame is
115% of the matched-curves design's width; its height and crescent are unchanged.
Use a solid fill without outlines, an enclosing ring, or decoration. The primary
icon color is the website's orange `#E95E00`. White and dark `#1F1A15` are the
approved monochrome treatments.

Run `pnpm brand:generate` from the repository root after an approved master edit.
It generates the shared web path, favicon, public SVGs, native template vector,
native brand color, and every macOS app icon size. The web Logo and Apple icon use
the generated path; the macOS welcome screen and scene rail use the BrandMark
asset through CampLogo. Every color instance uses `#E95E00`; the app tile places
the orange mark on a dark rounded square.

Earlier studies under `apps/macos/design/logo-concepts` are historical concepts,
not production assets. Do not restore a prior concept or a stock flame as branding.

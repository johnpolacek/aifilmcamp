# AI Film Camp — Flare variations

Five selection-stage variations retain Flare's core construction: one amber flame with a lens represented by negative space.

- **A — Balanced:** original proportion and circular lens
- **B — Compact:** shorter silhouette and smaller lens for app-icon density
- **C — Orbit:** asymmetric body and offset lens for more motion
- **D — Iris:** six-sided aperture for a more technical reading
- **E — Cinema:** wide lens-shaped opening for a stronger film association

Primary amber: `#F5A623`. The individual SVGs have transparent backgrounds and contain only one filled vector path. The comparison board also demonstrates monochrome dark, reversed white, and 36-pixel use.

After a variation is selected, the final package should include amber, charcoal, and white SVGs plus macOS app-icon and website-header usage tests.

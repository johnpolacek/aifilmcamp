# AI Film Camp — Flare width study

This study changes one variable from the Balanced Flare: the horizontal scale of the outer flame. Height, circular lens size, lens position, amber, and vertical spacing remain fixed.

- **Wider:** 110% outer width
- **More Wide:** 120%
- **Wider Still:** 130%
- **Really Wide:** 142%
- **Super Wide:** 155%

Balanced is the 100% reference. Each SVG has a transparent background and uses `#F5A623`. The board also tests the silhouettes at 36 pixels and in reversed white.

# AI Film Camp — Wider Still crescent-lens study

These five selection-stage variations preserve the 130% **Wider Still** flame and replace its circular opening with a charcoal lens containing a warm-white moon-shaped reflection.

- **A — Classic Crescent:** balanced upper-left reflection
- **B — Bold Halo:** broad, high-contrast crescent
- **C — Fine Sliver:** thinner and more technical
- **D — High Glint:** compact, understated reflection
- **E — Crescent Sweep:** broad C-shaped moon closest to the supplied visual reference

Colors:

- Amber flame: `#F5A623`
- Charcoal lens: `#191715`
- Warm-white reflection: `#FFF8ED`

All individual SVGs have transparent backgrounds. The comparison board tests each at 38 pixels and on a dark rounded-square tile.
